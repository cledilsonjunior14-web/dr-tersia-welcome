# Página de links da Dra. Tess

Entendi perfeitamente — e essa dinâmica é bem melhor do que transformar o link da bio em um questionário aberto logo de cara.

A página precisa funcionar como uma porta de entrada simples, com duas decisões principais.

ENTROU PELO LINK DA BIO
        ↓
┌───────────────────────────────┐
│   JÁ SOU PACIENTE             │
│   → vai direto para WhatsApp  │
└───────────────────────────────┘

┌───────────────────────────────┐
│ QUERO AGENDAR MINHA           │
│ PRIMEIRA CONSULTA             │
│ → abre mini-quiz              │
└───────────────────────────────┘

Fluxo que eu desenharia

1. Página inicial

Nada de vários cards, florzinha, ícones decorativos ou cara de “linktree”.

Eu faria algo mais editorial, premium e médico, usando a própria Dra. como elemento visual.

Estrutura:

┌───────────────────────────────────┐
│ DRA. TÉRSIA GUIMARÃES            │
│ Ginecologia • Obstetrícia •       │
│ Saúde íntima                      │
│                                   │
│ [ FOTO DA DRA. ]                  │
│                                   │
│ Cuidar da sua saúde começa        │
│ entendendo o que você precisa.    │
│                                   │
│ [ Quero agendar minha             │
│   primeira consulta ]             │
│                                   │
│ [ Já sou paciente ]               │
│                                   │
│ Atendimento particular • Sobral   │
└───────────────────────────────────┘

O botão principal seria bem mais forte:

Quero agendar minha primeira consulta

O secundário:

Já sou paciente

Sem mais distrações.

Se clicar em “Já sou paciente”

Não tem quiz.

Vai direto para o WhatsApp com mensagem pré-preenchida:

Olá, já sou paciente da Dra. Térsia e gostaria de atendimento.

A Íris recebe e segue o fluxo de paciente atual.

Se clicar em “Quero agendar minha primeira consulta”

A página escurece levemente e abre um modal grande, praticamente como uma experiência própria.

Não chamaria de formulário.

Algo como:

Vamos entender como podemos te atender.
São só algumas informações rápidas.

E aí começa o fluxo.

Etapa 1 — Nome

Olá! Como podemos te chamar?

[ Seu primeiro nome ]

             Continuar →

Nesse momento já temos:

nome

Etapa 2 — WhatsApp

Pra qual número podemos continuar
seu atendimento?

[ (88) 99999-9999 ]

             Continuar →

Aqui já temos:

nome + telefone

E aqui está um detalhe que eu recomendo tecnicamente:

já criar o lead no CRM nesse momento.

Mesmo que ela abandone depois, nós capturamos:

Nome
Telefone
Origem: Instagram / Link da bio
Status: iniciou qualificação

Ou seja, não esperar o fim do quiz para registrar.

Etapa 3 — O que ela está procurando?

Aqui sim entramos em qualificação.

Eu evitaria perguntar:

“Qual procedimento você deseja?”

Porque às vezes ela nem sabe o nome.

Melhor:

O que fez você procurar a Dra. Térsia hoje?

Botões grandes:

Consulta ginecológica / prevenção

Estética e saúde íntima

Gestação / pré-natal

Outro motivo

Sem ícones ou, no máximo, pequenos ícones lineares muito discretos.

Etapa 4 — pergunta contextual

A quarta pergunta muda dependendo da resposta anterior.

Se escolheu ginecologia:

O que você gostaria de fazer?

Consulta ginecológica

Consulta + prevenção

Quero uma avaliação mais completa

Ainda não sei

Se escolheu estética íntima:

Qual assunto mais se aproxima
do que você procura?

Ninfoplastia

Clareamento íntimo

Laser íntimo

Preenchimento íntimo

Ainda não sei qual é o mais indicado

Se escolheu gestação:

Você está buscando:

Iniciar pré-natal

Continuar acompanhamento

Ultrassom / exame

Outra orientação

Isso já entrega para a Íris uma pessoa pré-qualificada.

Final

Nada de página enorme de “resultado do quiz”.

Algo simples:

Tudo certo, Ana.

Já registramos suas informações.

Agora vamos continuar seu atendimento
pelo WhatsApp.

[ Continuar no WhatsApp ]

O WhatsApp abriria já com mensagem montada automaticamente:

Olá, sou Ana. Vim pelo Instagram e estou buscando atendimento pela primeira vez. Meu interesse é estética íntima, especialmente clareamento íntimo.

E paralelamente o CRM teria algo assim:

Nome: Ana
Telefone: 88...
Origem: Instagram
Canal: Link da bio
Paciente: primeira vez
Trilha: Estética íntima
Interesse: Clareamento íntimo
Etapa: Novo Contato
Quiz concluído: sim

Quando ela chegar na Íris, a conversa não começa:

“Como posso ajudar?”

A Íris já pode começar:

“Oi, Ana. Vi que você está buscando informações sobre clareamento íntimo. Me conta: o que despertou seu interesse nesse tratamento?”

É aí que essa página começa a gerar valor comercial de verdade.

Sobre o visual: eu mudaria completamente o caminho anterior

Concordo com você que não ficou com a cara certa.

Não usaria mais:

florzinha;

bolinhas decorativas;

estética “feminina genérica”;

muitos cards;

bordas em tudo;

degradês exagerados;

visual de SaaS;

layout de quiz tradicional.

Eu trabalharia uma identidade assim:

Fundo

off-white quente / bege muito claro

Exemplo:
#F5EFEA

Vinho principal

Extraído do blazer/identidade que você mostrou:

algo próximo de:
#8F2F2D
ou
#9F302F

Vinho profundo

Para texto e botões secundários:

#4B2425

Texto

Quase preto quente:

#282322

Bege intermediário

#DCCDC3

Branco

#FFFDFB

Sem rosa como elemento obrigatório.

Sensação visual

Eu buscaria algo entre:

editorial médico + quiet luxury + feminino sofisticado

Não:

clínica rosa / estética feminina clichê.

A foto da Dra. teria muito peso.

Por exemplo:

┌─────────────────────────────────┐
│ DRA. TÉRSIA GUIMARÃES          │
│                                 │
│        foto da Dra.             │
│        ocupando 45%             │
│        da primeira tela         │
│                                 │
│ Sua saúde merece uma            │
│ avaliação individual.           │
│                                 │
│ ┌─────────────────────────────┐ │
│ │ Agendar primeira consulta   │ │
│ └─────────────────────────────┘ │
│                                 │
│       Já sou paciente           │
└─────────────────────────────────┘

No mobile, que será praticamente todo o tráfego, isso ficaria muito bonito.

Um detalhe que eu adicionaria

No rodapé da primeira tela, bem discreto:

Ginecologia • Obstetrícia • Medicina Fetal • Saúde Íntima
Atendimento particular em Sobral — CE

Isso posiciona sem lotar a página.

Arquitetura final

Eu passaria para o Claude exatamente esta lógica:

LANDING
│
├── Já sou paciente
│      └── WhatsApp direto
│
└── Primeira consulta
       │
       ├── Nome
       │
       ├── WhatsApp
       │     └── criar lead no CRM
       │
       ├── Motivo da procura
       │
       ├── Qualificação contextual
       │
       └── Continuar no WhatsApp
              │
              └── mensagem preenchida +
                  dados já salvos no CRM

E eu ainda enviaria UTM, campanha, conjunto e anúncio para o CRM quando essa pessoa vier de tráfego pago. Assim teríamos:

anúncio → landing → qualificação → WhatsApp → Íris → agendamento → paciente.

Esse desenho está muito mais próximo do que eu faria para a Dra. Térsia.
